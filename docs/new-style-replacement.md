# Замена дизайна без изменений старого кода

Дата: 2026-11-26

## Зачем

Сайт сделан по мотивам маркетплейса, и две детали сразу выдают заимствование:

- фиолетовый градиент шапки (`src/app/styles/Layout.module.css`, `.layoutHeader`) — заменён на `--header-gradient`;
- фиолетовая кнопка «Добавить» в карточке товара — заменена на акцент `--color-accent` (`Button`, `AddBasket` и все остальные места); hover — `--color-accent-hover`.

Нужно подобрать свой визуальный язык, **не меняя**:

- сетку, отступы, размеры и расположение элементов на десктопе и мобильных;
- поведение поиска, корзины, избранного и быстрого просмотра;
- футер и остальные страницы.

## Где живёт новый стиль

Весь модуль preview находится в одной папке — `src/app/new-styles/`. Удаление этой папки убирает только страницу сравнения: одобренный градиент шапки уже вынесен в `src/app/styles/globals.css` и используется основным приложением. Зависимости не добавлялись.

```
src/app/new-styles/
├── page.tsx                                   # маршрут /new-styles
└── components/
    ├── PreviewShell/                          # панель подбора градиента шапки и макет превью
    │   ├── PreviewShell.tsx
    │   └── PreviewShell.module.css
    ├── HeaderNewStyle/                        # копия шапки с новыми цветами
    │   ├── HeaderNewStyle.tsx
    │   └── HeaderNewStyle.module.css
    └── ProductCardNewStyle/                   # копия карточки товара с новыми цветами
        ├── ProductCardNewStyle.tsx
        └── ProductCardNewStyle.module.css
```

Страница превью: `http://localhost:3000/new-styles`.

## Как пользоваться

1. `npm run dev`.
2. Открыть `/new-styles`.
3. Палитра зафиксирована на **Графите**. Верхняя панель переключает два варианта шапки: **Без** (сплошной графит) и **Радуга**. Выбор дублируется в URL: `/new-styles?gradient=rainbow`.
4. Проверять на ширинах 375 / 768 / 1024 / 1440: сетка и отступы должны совпадать с главной.

Превью само скрывает старую шапку: правило живёт в `PreviewShell.module.css` и работает только пока на странице есть атрибут `data-new-style-preview`. Футер, `MenuWrapper`, модальные окна и корзина остаются теми же.

## Что именно поменялось визуально

| Элемент                   | Было                         | Стало                                      |
| ------------------------- | ---------------------------- | ------------------------------------------ |
| Фон шапки                 | градиент `#3a1367 → #cf16b9` | сплошной `#222b33` или фирменная «Радуга»  |
| Кнопка «Добавить»         | `#a73afd`                    | `--color-accent: #2f6b8a`, hover `#22536e` |
| Счётчик товара в карточке | `#f4e7ff`                    | `--color-accent-soft: #e7f0f5`             |
| Кнопка быстрого просмотра | белая                        | светлый акцент темы, по наведению — акцент |
| Фон карточки и картинки   | `#fff` / `#f9f9fa`           | `#fbfcfd` / `#eef2f5`                      |
| Сердечко избранного       | красный/фиолетовый hover     | `--color-accent-hover: #22536e`            |

Варианты шапки переключаются кнопками в панели:

- **Без** — сплошной `#222b33`, пока единственный полностью устраивающий вариант.
- **Радуга** — фирменный градиент под название магазина: зелёный `#166534` 26% → бирюзовый `#0f766e` 46% → индиго `#1e3a8a` 64% → фиолетовый `#6b21a8` 84%.

Этот же градиент лежит в `--header-gradient` в `globals.css` и используется основной шапкой. Красного, жёлтого и оранжевого больше нет; белый текст сохраняет контраст не ниже 7:1 на любом участке, синие кнопки `#2f6b8a` не теряются. Остальные эксперименты (WB, «Ночь», «Аметист», «Коралл», «Янтарь») убраны из панели.

Геометрия карточки (`aspect-ratio: 3/4`, `padding: 6px`, радиусы, сетка 6/5/4/3/2 колонок) скопирована один в один. Рамка карточки и панели подбора градиента сделана через `box-shadow: inset …` (`--ns-card-frame` / `--ns-card-frame-hover`), не через `border`, поэтому толщина рамки не влияет на размеры. Логика поиска и корзины не дублируется: `HeaderNewStyle` и `ProductCardNewStyle` переиспользуют существующие компоненты и store.

## Как добавить ещё одну страницу в превью

1. Добавить секцию в `PreviewShell.tsx` рядом с сеткой товаров и передать туда те же CSS-переменные градиента.
2. Если нужна новая копия компонента — положить её в `src/app/new-styles/components/<Name>/`.
3. Не импортировать новые компоненты из старых файлов: иначе модуль перестанет быть удаляемым.

## Как перенести понравившийся вариант в продакшн

1. Выбрать градиент в панели и запомнить его значения из `PreviewShell.module.css`.
2. Акцентные переменные (`--color-accent`, `--color-accent-hover`, `--color-accent-soft`) уже лежат в `src/app/styles/globals.css`; превью берёт их оттуда через `var(--color-accent*)`.
3. Градиент шапки уже применён: `--header-gradient` лежит в `src/app/styles/globals.css`, а `.layoutHeader` в `src/app/styles/Layout.module.css` использует `background-image: var(--header-gradient)`. Остальные правила из `HeaderNewStyle.module.css` переносить не обязательно.
4. Внести правила из `ProductCardNewStyle.module.css` в `src/widgets/product/ProductCard/ProductCard.module.css`, `AddBasket.module.css` и `QuickViewButton.module.css`.
5. Удалить `HeaderNewStyle`, `ProductCardNewStyle`, страницу `/new-styles` и этот файл.
6. Прогнать `npx tsc --noEmit`, `npx eslint .` и `npm run build`.

`src/app/layout.tsx` не тронут: подмена шапки в нём не требуется. В основном приложении изменены шапка и акцент кнопок/ссылок/обводок — геометрия и поведение остаются прежними.

## Как полностью откатиться

```bash
rm -rf src/app/new-styles docs/new-style-replacement.md
```

После этого исчезает только страница сравнения: градиент шапки останется, потому что живёт в `globals.css` и `Layout.module.css`.
